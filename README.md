# CareerFlow Admin Backend (Phase 1)

Simple backend for the CareerFlow Admin Panel.
Handles admin login with JWT authentication.

---

## Requirements

- Node.js v18+
- MongoDB v6+ (local or Atlas)
- npm or yarn

---

## Setup Instructions

### 1. Install Node.js

Download from [https://nodejs.org](https://nodejs.org)

Verify:
```bash
node -v
npm -v
